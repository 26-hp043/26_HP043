**입력**

- [ ] 배지에 **패턴(촘촘한 대각선)이 보인다** — 색만으로 등급을 전달하지 않는다(`DESIGN_SYSTEM §14`)

| 항목 | 기대 표시 |
|---|---|
| 참고 등급 | `C` |

| 항차 조건 기준 예상 CII | `4.982` `gCO₂/(DWT·nm)` |
| 기준 CII | `5.045` `gCO₂/(DWT·nm)` |
| 기준 대비 비율 | `98.8%` |
| CO₂ 배출량 | `249.1` `t` |
| 연료 사용량 | `80.0` `t` |
| 항해거리 | `1,000` `nm` |

- [ ] **경고**가 보인다 → `참고용 예측값입니다. 규제 제출용이 아닙니다.`
- [ ] **추정값 고지**가 보인다 → 「이 화면의 수치는 모두 입력한 항차 조건에 기반한 추정값입니다」
- [ ] 「**연말**」·「**누적**」 같은 표현이 화면에 **없다**

### 표기 규칙 확인

- [ ] CII 3개(`4.982` · `5.045`)에 **천단위 구분자가 없다**
- [ ] 항해거리 `1,000`에 **구분자가 있다**
- [ ] 비율이 `0.988`이 아니라 **`98.8%`** 로 나온다
- [ ] 단위가 `gCO₂/(DWT·nm)` — **괄호가 있고**, `t`가 아니라 `DWT`이며, `AER`이 병기되지 않는다

## 3. 입력 변화 확인

> ⚠️ **무엇이 무엇을 바꾸는지 알고 확인한다.**
>
> ```
> CO₂ = Σ(연료량 × CF × 1,000,000)
> CII = CO₂ ÷ (capacity × 거리)
> ```
>
> | 변경 | CO₂ | CII |
> |---|---|---|
> | 연료량 | 같은 방향 | 같은 방향 |
> | 거리 | **그대로** | 반대 방향 |
> | 연료 종류 | CF에 따라 | 함께 변함 |
> | 속력 | **그대로** | **그대로** |
>
> **거리를 바꿨는데 CO₂가 그대로인 것은 정상이다.** 오류로 판단하지 않는다.

### A. 연료량만 변경 — 거리 `1000` 고정

| 연료 | CII | CO₂ | 등급 | 위험도 | 여유율 |
|---|---|---|---|---|---|
| `70` | `4.360` | `218.0` | **B** | `낮음 LOW` | `C 등급까지 7.6%` |
| `80` | `4.982` | `249.1` | **C** | `보통 MEDIUM` | `D 등급까지 7.2%` |
| `85` | `5.294` | `264.7` | **C** | `높음 HIGH` ⚠ | `D 등급까지 1.1%` |
| `90` | `5.605` | `280.3` | **D** | `높음 HIGH` ⚠ | `E 등급까지 6.9%` |

- [ ] 연료를 올리면 **CO₂와 CII가 함께 오른다**
- [ ] 항해거리 표시는 `1,000`으로 **변하지 않는다**
- [ ] `85`에서 등급은 `C` 그대로인데 **위험도만 `높음 HIGH`로 바뀐다** — 등급 경계는 안 넘고 여유율 기준선(3%)만 넘은 경우다
- [ ] `높음 HIGH`에 **경고 아이콘 ⚠ 이 붙는다**. `보통`·`낮음`에는 **붙지 않는다**

### B. 거리만 변경 — 연료 `80` 고정

| 거리 | CO₂ | CII | 등급 | 위험도 |
|---|---|---|---|---|
| `900` | `249.1` | `5.536` | **D** | `높음 HIGH` ⚠ |
| `1000` | `249.1` | `4.982` | **C** | `보통 MEDIUM` |
| `1100` | `249.1` | `4.529` | **B** | `보통 MEDIUM` |
| `1200` | `249.1` | `4.152` | **A** | `보통 MEDIUM` |

- [ ] **CO₂가 `249.1` 로 전부 같다** — 이것이 이 항목의 핵심이다
- [ ] 거리를 늘리면 **CII가 내려간다**(반대 방향)
- [ ] `1200`에서 등급이 **A**가 되고 배지에 **패턴이 사라진다** — A는 solid다(`DESIGN_SYSTEM §15.1`)

### C. 연료 종류만 변경 — 거리 `1000` · 연료량 `80` 고정

| 연료 종류 | CF | CO₂ | CII | 등급 | 위험도 |
|---|---|---|---|---|---|
| `Methanol (METHANOL)` | 1.375 | `110.0` | `2.200` | **A** | `낮음 LOW` |
| `Liquefied Natural Gas (LNG)` | 2.750 | `220.0` | `4.400` | **B** | `낮음 LOW` |
| `Heavy Fuel Oil (HFO)` | 3.114 | `249.1` | `4.982` | **C** | `보통 MEDIUM` |
| `Diesel/Gas Oil (DIESEL_GAS_OIL)` | 3.206 | `256.5` | `5.130` | **C** | `보통 MEDIUM` |

- [ ] 연료 사용량 표시는 `80.0`으로 **변하지 않는다** — 바뀐 것은 CF다
- [ ] CF가 낮은 연료일수록 CO₂와 CII가 **함께 낮아진다**

### D. 속력만 변경 — 거리 `1000` · 연료 `80` 고정

| 속력 | 결과 |
|---|---|
| `1.0` | 아래 전부 기준 시나리오와 **완전히 동일** |
| `14.2` | (기준) |
| `25` | 위와 **완전히 동일** |

- [ ] CII · CO₂ · 등급 · 위험도 · 여유율이 **하나도 바뀌지 않는다**
- [ ] 폼의 보조 문구가 이 사실을 미리 알리고 있다

## 4. 등급 경계 확인 — 1 t 차이로 넘어간다

> 등급은 **경계를 넘을 때만** 바뀐다. 아래는 경계를 넘도록 미리 정한 입력이다.

### A/B 경계 — 거리 `1000` 고정

- [ ] 연료 `69` → 등급 **A** · CII `4.297` · 여유율 `B 등급까지 0.8%`
- [ ] 연료 `70` → 등급 **B** · CII `4.360` · 여유율 `C 등급까지 7.6%`
- [ ] 배지 패턴이 **없음(A) → 성긴 대각선(B)** 으로 바뀐다

### C/D 경계 — 거리 `1000` 고정

- [ ] 연료 `85` → 등급 **C** · CII `5.294`
- [ ] 연료 `86` → 등급 **D** · CII `5.356` · 여유율 `E 등급까지 11.8%`
- [ ] 배지 패턴이 **촘촘한 대각선(C) → 도트(D)** 로 바뀐다

### 최하위 등급 E — 여유율 자리가 문구로 바뀐다

- [ ] 연료 `100` → 등급 **E** · CII `6.228` · CO₂ `311.4`
- [ ] 여유율 자리에 숫자가 아니라 **`해당 없음 — 최하위 등급`** 이 나온다
- [ ] 위험도가 **`심각 CRITICAL`** 이고 **⚠ 아이콘**이 붙는다
- [ ] 배지 패턴이 **크로스해치**다

## 5. 입력 오류 확인 — 화면이 중단되지 않는다

각 항목은 **해당 입력창 바로 아래**에 한국어 메시지가 나와야 한다.

- [ ] 항해거리 `0` → `항해거리는 0보다 커야 합니다.`
- [ ] 항해거리 빈칸 → `항해거리를 입력해 주세요.` (「0보다 커야」가 **아니다**)
- [ ] 평균 속력 `0.5` → `속도는 1.0노트 이상이어야 합니다.`
- [ ] 연료 사용량 `0` → `연료 사용량은 0보다 커야 합니다.`
- [ ] 연료 종류 미선택 → `연료 종류를 선택해 주세요.`

**동시 표시 확인**

- [ ] 네 필드를 **전부 비우고** [계산하기] → **오류 4개가 한 번에** 표시된다 (하나씩 나오지 않는다)
- [ ] 오류가 난 입력창의 **테두리 색이 바뀌고**, 그와 별개로 **아래 메시지가 항상 붙는다**
- [ ] 오류 상태에서도 **화면 전체가 깨지지 않고 면책 배너가 그대로 있다**
- [ ] 한 필드를 고치면 **그 필드의 오류만 사라지고** 나머지는 남아 있다
- [ ] [계산하기]를 누른 직후 버튼이 **`계산 중…`으로 바뀌며 비활성**된다

## 6. 기능② 시나리오 비교 — `/route-comparison`

- [ ] 사이드바 **항로 비교**로 진입된다
- [ ] 카드 3장이 **직항 · 우회 · 감속** 순서로 보인다

| 시나리오 | 거리 | 속력 | 소요시간 | 연료 | CO₂ | CII | 등급 | 위험도 | 여유율 |
|---|---|---|---|---|---|---|---|---|---|
| 직항 | `1,000` nm | `14` kn | `71.4` h | `80.0` t | `249.1` t | `4.982` | **C** | `보통 MEDIUM` | `D 등급까지 7.2%` |
| 우회 | `1,050` nm | `14` kn | `75.0` h | `88.0` t | `274.0` t | `5.220` | **C** | `높음 HIGH` ⚠ | `D 등급까지 2.5%` |
| 감속 | `1,000` nm | `13` kn | `76.9` h | `69.0` t | `214.9` t | `4.297` | **A** | `보통 MEDIUM` | `B 등급까지 0.8%` |

- [ ] **감속이 등급을 `C → A`로 개선**하는 것이 보인다
- [ ] **우회만 위험도가 `높음 HIGH`** 이고 ⚠ 아이콘이 붙는다
- [ ] 직항 값이 **§2 기준 시나리오와 같다** — 기능①과 기능②가 같은 계산을 쓴다는 증거

### 지표별 최소값 — 추천이 아니다

- [ ] 카드 아래에 세 줄이 보인다

| 줄 | 기대 |
|---|---|
| CII가 가장 낮은 시나리오 | `감속` |
| 소요시간이 가장 짧은 시나리오 | `직항` |
| 연료 사용량이 가장 낮은 시나리오 | `감속` |

- [ ] **세 줄의 답이 서로 다르다** — 하나를 「추천」하지 않는다는 것이 이 표기의 핵심이다
- [ ] 화면에 「추천」·「최적」 같은 단어가 **없다**
- [ ] 상단 고지에 다음 두 문장이 보인다 (`PRD §6.3` 원문)
  > 일부 값은 사용자 입력 또는 모델 추정값입니다. 시스템은 시나리오별 수치만 비교하며, 최종 운항 판단은 사용자에게 있습니다.
- [ ] 면책 배너가 **여기에도** 보인다

## 10. 이 데모가 하지 않는 것

시연 중 질문이 나올 수 있는 항목이다. **미구현이 아니라 범위 밖**이라는 구분이 필요하다.

| 항목 | 상태 |
|---|---|
| 백엔드 API 연결 | demo provider로 동작한다. 실 API 연결은 `#138`(기능①) · `#139`(기능②) |
| 샘플 선박 2·3번 | `#34` 회신 대기. 정본값 fixture가 없어 선택지에 넣지 않는다 |
| 2026 외 규제연도 | `required_cii`가 Z계수에 걸려 연도마다 다르고 `regulation_year` 설정 경로는 `#150` 미해결 |
| 다중 연료 행 | 계약은 배열이나 화면은 단일 행이다. 제출 시 길이 1의 배열로 변환한다 |
| 항차 저장 | 출발항·도착항·메모·연간 반영 여부는 항차 저장 경로(`API_SPEC §3.3`)이며 범위 밖 |
| 기능② 실제 연료 추정 | 시나리오별 고정값이다. cubic speed model은 `#75` |
| 기능③ 실제 계산 | 전 항목 고정 상수다. 엔진 `#63` · API `#64`는 `2026.10` 마일스톤 |
| 확률 표기 `P(D∪E)` | 계산 정의가 `PRD`에 없다(`#170` 확인 ⑶). 임계값도 초안이다 |
| 지도 기반 항로 시각화 | `UIFLOW §2-2`가 기술하나 8/8 범위 밖 |
